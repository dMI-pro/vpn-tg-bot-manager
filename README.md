# VPN Telegram Bot Manager

Telegram бот для управления вашими VPS серверами и конфигурациями WireGuard.

## Основные возможности

- 🖥 **Управление VPS**: Добавление, удаление и мониторинг состояния серверов.
- 🔑 **WireGuard**: Автоматическая генерация конфигураций и QR-кодов.
- 📊 **Мониторинг**: Автоматическая проверка доступности серверов каждые 30 минут.
- 🛡 **Безопасность**: Шифрование паролей SSH, rate limiting и защита от спама.
- 💾 **Бэкапы**: Ежедневное резервное копирование базы данных.

## Требования

- **Node.js**: v18 или выше
- **npm**: v9 или выше
- **VPS**: Ubuntu/Debian с установленным WireGuard (или скрипт установит его автоматически при первой настройке)
- **PM2**: Рекомендуется для управления процессом

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone <your-repo-url>
   cd vpn-tg-bot-manager
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Создайте файл `.env` в корне проекта:
   ```env
   BOT_TOKEN=ваш_токен_бота_от_BotFather
   ENCRYPTION_KEY=ваш_ключ_шифрования_32_символа
   DATABASE_PATH=vpn-bot.db
   ```

4. Соберите проект:
   ```bash
   npm run build
   ```

5. Запустите бота:
   ```bash
   npm start
   ```

## Деплой

Для быстрого обновления и перезапуска используйте скрипт:
```bash
./scripts/deploy.sh
```

## Доступные команды

- `/start` - Начало работы и приветствие
- `/add_vps` - Пошаговое добавление нового сервера
- `/my_vpss` - Список ваших серверов и их статус
- `/update_vps_password` - Обновление SSH пароля сервера
- `/create_config` - Генерация нового VPN конфига
- `/my_configs` - Управление вашими конфигурациями (скачивание, удаление)
- `/health` - (Админ) Общая статистика системы
- `/refresh_vps <id>` - Принудительная проверка статуса сервера

## Структура проекта

- `src/index.ts` - Точка входа, middleware и инициализация
- `src/database/` - Модуль работы с SQLite
- `src/ssh/` - Менеджер SSH соединений
- `src/commands/` - Обработчики команд и сцены Telegraf
- `src/services/` - Фоновые задачи (мониторинг, бэкапы)
- `src/utils/` - Утилиты (шифрование, логгер, WG утилиты)
